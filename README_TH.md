# Boom Local MCP — คู่มือใช้งาน

Boom ให้ ChatGPT ทำงานบนคอมพิวเตอร์ Windows ของคุณได้จริง ทั้งไฟล์ แอป หน้าจอ เบราว์เซอร์ Office และโค้ด สั่งจากแชตบนคอมหรือมือถือก็ได้ ความปลอดภัยอยู่ใน Boom เอง งานที่มีผลจริง (เช่น ลบไฟล์ ส่งงานขึ้น Git ปิดหน้าต่าง) Boom จะรอให้คุณอนุมัติก่อนทุกครั้ง

> English: [README.md](README.md) · แผนงานต่อไป: [ROADMAP.md](ROADMAP.md)

## 1. ติดตั้ง (Windows 10/11)

1. ดาวน์โหลด `BoomSetup-<version>-r<N>.exe` จาก [release ล่าสุด](https://github.com/ThanawatSSS/boom-local-mcp-releases/releases/latest)
2. เปิดไฟล์แล้วติดตั้ง
   - ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล Windows อาจขึ้นว่า "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway**
   - Boom ติดตั้งเฉพาะบัญชี Windows ของคุณ ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ
3. เมื่อเสร็จ Boom Control จะเปิดขึ้น และมีไอคอน **B** ที่มุมขวาล่างของจอ (system tray)

ครั้งต่อไป Boom เริ่มเองเมื่อเปิดเครื่อง และแจ้งเมื่อมีรุ่นใหม่ในหน้า **อัปเดต** ของ Boom Control โดยจะอัปเดตเมื่อคุณกดเท่านั้น

## 2. เชื่อมต่อกับ ChatGPT (ทำครั้งเดียว)

Boom คุยกับ ChatGPT ผ่าน Secure MCP Tunnel ของ OpenAI ในบัญชีของคุณเอง ไม่ต้องเปิดพอร์ตหรือใช้เซิร์ฟเวอร์สาธารณะ หน้า "เชื่อมต่อเครื่องนี้" ใน Boom Control พาทำทีละขั้น:

1. สร้าง Tunnel ใน OpenAI Platform แล้วคัดลอก `tunnel_id` (ขึ้นต้นด้วย `tunnel_`)
2. สร้าง API key ในบัญชีเดียวกัน (ต้องมีสิทธิ์ Tunnels: Use) Boom เก็บ key ไว้ในเครื่องนี้เท่านั้น
3. ใส่ทั้งสองค่าใน Boom Control แล้วกด **เชื่อมต่อ**
4. ใน ChatGPT: Settings → Security and login → เปิด **Developer mode** → Plugins → **+** → Connection เลือก **Tunnel** → เลือก tunnel ของคุณ → ตั้งชื่อ "Boom"

เปิดแชตใหม่แล้วพิมพ์ `เช็กสุขภาพ Boom` ถ้า Boom Control ขึ้นว่า ChatGPT เชื่อมต่อแล้วก็พร้อมใช้งาน

> หลังอัปเดต Boom ให้กด Refresh ที่ Plugin "Boom" ใน ChatGPT แล้วเปิดแชตใหม่ เพื่อให้ ChatGPT เห็นเครื่องมือรุ่นล่าสุด

## 3. ใช้งาน: พิมพ์บอกเป้าหมายเป็นภาษาปกติ

ไม่ต้องบอกว่าให้ใช้เครื่องมือไหน GPT จะเลือกวิธีที่เหมาะเอง ตัวอย่าง:

| อยากทำ | ลองพิมพ์ | สิ่งที่เกิดขึ้น |
|---|---|---|
| ดูหน้าจอ | `ขอดูหน้าจอคอมตอนนี้หน่อย` | ภาพหน้าจอขึ้นในแชต |
| เปิดแอปแล้วพิมพ์ | `เปิด Notepad แล้วพิมพ์ว่า "สวัสดีจาก Boom" ไม่ต้องบันทึก` | แถบ Boom ขึ้นบนจอ แล้วพิมพ์ให้ Boom ตรวจว่าข้อความลงจริง |
| ใช้แอปใดก็ได้ | `เปิด Paint แล้ววาดบ้านหลังเล็ก ๆ มีหลังคา ประตู และหน้าต่าง` | การ์ดงานแสดงขั้นตอน และภาพล่าสุดที่ Boom เห็น |
| เบราว์เซอร์ | `เปิดเพลงอะไรก็ได้ใน YouTube Music ที่เปิดไว้ใน Brave` | Boom หาแท็บให้เองโดยไม่ต้องไล่ทีละแท็บ |
| ไฟล์ | `สร้างไฟล์ notes.txt ใน Documents เขียนว่า ประชุมวันจันทร์` | สร้างไฟล์ในโฟลเดอร์ที่อนุญาต |
| หาไฟล์ | `หาไฟล์ PDF ใน Downloads ที่ชื่อมีคำว่า invoice` | รายชื่อไฟล์ที่ตรง |
| ลบไฟล์ | `ลบไฟล์ report-old.txt ใน Documents` | การ์ดอนุมัติ → ย้ายไปถังขยะ กู้คืนได้ |
| ลบตามกฎ | `ลบไฟล์ .tmp ใน Downloads ที่เก่ากว่า 1 ต.ค. ยกเว้น keep.tmp` | GPT ทวนกฎ → การ์ดเดียวแสดงจำนวน กลุ่มโฟลเดอร์ และรายชื่อทั้งหมด |
| Excel | `เปิด budget.xlsx ใน Documents แล้วรวมยอดคอลัมน์ C` | อ่านและเขียนสเปรดชีตโดยไม่ต้องใช้เมาส์ |
| โค้ด/Git | `ดู git status ของโปรเจกต์ my-app แล้วสรุปว่าแก้อะไรไปบ้าง` | สรุปการเปลี่ยนแปลง การ push ต้องอนุมัติ |
| ข้อมูลเครื่อง | `คอมผมหลับไปครั้งล่าสุดเมื่อไหร่ นานเท่าไร` | อ่านจาก Windows Event Log |
| งาน 3D | `ทำเก้าอี้กินข้าวไม้ใน SketchUp แบบละเอียดพิเศษ ถอดชิ้นไปทำจริงได้ บันทึกไว้ที่ Documents\boom-3d\chair.skp` | GPT ถามสิ่งที่ยังไม่ชัด แล้วทำตามวิธีของช่างทีละขั้น ตรวจทุกด้าน และส่งงานพร้อมรายการตัดไม้ |
| งานหลายขั้น | `จัดไฟล์ใน Downloads ตามประเภท แล้วแสดงความคืบหน้าให้ดู` | การ์ดงานบอกว่าทำถึงขั้นไหน |

เคล็ดลับ:
- บอก **ผลที่ต้องการ** ให้ชัด เช่น ไฟล์ไหน โฟลเดอร์ไหน แล้วให้ GPT เลือกวิธีเอง
- อยากเห็นผลงานเป็นภาพ ให้เติมว่า `ส่งภาพหน้าจอผลลัพธ์มาด้วย`
- บนมือถือ (โดยเฉพาะ iPhone) ChatGPT อาจแสดงการ์ดงานตอนทำเสร็จแล้ว ถ้าอยากดูระหว่างทำ เปิดหน้า **งาน** ใน Boom Control บนคอมได้

## 4. การอนุมัติ

- งานที่มีผลจริงจะขึ้น **การ์ดอนุมัติ** ในแชต และใน Boom Control บนคอม ตัดสินใจที่ไหนก่อนก็ได้ ผลเหมือนกัน และไม่ทำซ้ำ
- ถ้าบนมือถือไม่เห็นการ์ด พิมพ์ `ไม่เห็นการ์ดอนุมัติ` GPT จะเรียกการ์ดเดิมขึ้นมาใหม่
- ถ้ามีหลายคำขอ การ์ดจะบอกว่า "ยังมีคำขออื่นรออีก N รายการ" ตัดสินใจใบนี้แล้วกด **ดูคำขอถัดไป**
- ระหว่างที่รออนุมัติ ไอคอน Boom มีเลขสีแดง และกะพริบเมื่อมีคำขอใหม่

## 5. ระหว่างที่ Boom ใช้หน้าจอ

แถบด้านล่างจอบอกสถานะ:

| แถบ | ความหมาย |
|---|---|
| สีเทา "กำลังดูหน้าจอ" | Boom แค่ดู ยังไม่ใช้เมาส์ |
| สีส้มและเลขใหญ่กลางจอ 3 · 2 · 1 | Boom กำลังจะใช้เมาส์ (ขึ้นเฉพาะตอนคุณใช้เครื่องอยู่) ปล่อยเมาส์ได้เลย |
| สีฟ้า | Boom กำลังใช้เมาส์และคีย์บอร์ด การคลิกของคุณถูกกันไว้ไม่ให้ชนกัน |
| สีเทา "รอขั้นถัดไปของงาน" | คุณใช้เครื่องได้ตามปกติ Boom จะนับถอยหลังก่อนกลับมาใช้เมาส์ |

ถ้าแตะเมาส์หรือคีย์บอร์ดตอนแถบสีฟ้า Boom จะหยุดถามว่าให้ทำต่อหรือคืนการควบคุม ถ้ากด **Esc ค้าง 1 วินาที** จะคืนการควบคุมทันที

## 6. ลบไฟล์และกู้คืน

- การลบปกติย้ายไฟล์ไป **ถังขยะ (Recycle Bin)** การ์ดที่ลบเสร็จมีปุ่ม **กู้คืน** ที่คืนเฉพาะไฟล์ของครั้งนั้น โดยไม่เขียนทับไฟล์ชื่อเดียวกันที่มีอยู่แล้ว
- การลบถาวรทำเฉพาะเมื่อคุณขอชัด เช่น `สร้างไฟล์ทดสอบแล้วลบทิ้งถาวร` การ์ดจะเขียนว่ากู้คืนไม่ได้
- ที่ที่ไม่มีถังขยะ (ไดรฟ์เครือข่าย ไดรฟ์ถอดได้ หรือไฟล์ใหญ่เกินถังขยะ) Boom จะไม่ลบ และบอกเหตุผลแทน

## 7. งาน 3D และวิธีทำงานของช่าง (Know-how)

Boom มี **วิธีทำงานของช่าง** ให้ AI ทุกตัวใช้แบบเดียวกัน งานจึงออกมาเป็นของที่ใช้จริงได้ ไม่ใช่กล่องต่อกัน:
- **ความรู้จากมาตรฐานอาชีพ** ที่หน่วยงานรับรองแล้ว (TPQI ของไทย และ ESCO ของยุโรป) แยกตามประเภทงาน: เปอร์สเปกทีฟและการคิดเป็นสามมิติ, การสร้างโมเดล 3 มิติ, ตัวละคร (เกมและแอนิเมชัน), สถาปัตยกรรม, งานก่อสร้าง, การออกแบบผลิตภัณฑ์ และการต่อชิ้นส่วนกับการประกอบ
- **ดู Know-how ทุกครั้งที่เริ่มงาน** งาน 3D เป็นประเภทแรกที่มี Know-how และจะมีประเภทอื่นตามมา ถ้างานไหนยังไม่มี GPT ก็ทำต่อตามปกติ
- **ถามเฉพาะสิ่งที่ยังไม่ได้บอกชัด:** ต้องการละเอียดระดับไหน (Mock-up, ละเอียด หรือละเอียดพิเศษที่ถอดเป็นชิ้นไปทำจริงได้) และจะทำในไฟล์ไหน (ไฟล์ใหม่ ไฟล์ที่เปิดอยู่ หรือไฟล์ที่ระบุ) ถ้าบอกมาชัดแล้วจะไม่ถามซ้ำ ถ้ายังไม่ชัด (เช่น "ขอสวยๆ") อาจถามให้ชัด ถ้าไม่ได้บอกเลยจะถามก่อนเริ่ม Boom คุมให้จริง: งานยังไม่เริ่มและยังไม่เปิด SketchUp หรือ Blender จนกว่าคำตอบของคุณเองจะตอบครบทุกข้อ จะตอบว่า "แล้วแต่คุณ" หรือ "ไม่เอาแล้ว" ก็ได้
- **งานละเอียดพิเศษ:** ทุกชิ้นแยกเป็นชิ้นจริงพร้อมข้อต่อ (เดือยกับรูเดือย ตัวยึด สกรูพร้อมรูนำ) ตรวจว่าไม่มีชิ้นไหนทับกัน และจำลองถอดเข้าออกได้ทุกขั้น พร้อมภาพแยกชิ้น ภาพทีละชิ้น และรายการตัดไม้จากโมเดล
- **ทุกชิ้นงานเป็นกลุ่มเดียว** ชิ้นที่ซ้ำกันใช้ต้นแบบเดียวกัน
- ทุกขั้นมีไฟล์จุดย้อนกลับ และมีบันทึกส่งต่อบอกว่าทำอะไร ใช้มาตรฐานอะไร ตรวจอะไรแล้ว และสร้างใหม่อย่างไร

โปรแกรมที่ใช้:
- **Blender** (ตัวละคร งานออร์แกนิก สิ่งของ): ต้องมี Blender 4.2 ขึ้นไป Boom เปิดไฟล์ .blend ดูครบทุกด้าน (บน ล่าง ซ้าย ขวา หน้า หลัง Iso และระดับสายตา) พร้อมขนาดเป็นเมตร โดยปิดสคริปต์ในไฟล์และไม่บันทึกทับ
- **SketchUp** (บ้าน อาคาร เฟอร์นิเจอร์): ถ้าติดตั้งส่วนเสริม *MCP Server for SketchUp* ไว้ GPT จะเปิด SketchUp พร้อมเริ่ม MCP ให้เลย ไม่ต้องกด Extensions → MCP Server for SketchUp → Start Server เอง ถ้าไม่มี GPT จะสั่ง SketchUp ผ่านสคริปต์ในหน้าต่างของมันเอง เปิด ทำ บันทึก แล้วปิด การเจาะข้อต่อด้วย Solid Tools ต้องใช้ SketchUp Pro
- ให้สิทธิ์ Boom เขียนไฟล์ในโฟลเดอร์งานก่อน (Boom Control → Workspace)
- **โปรแกรมอยู่ที่ไหนก็ได้:** Boom หาโปรแกรมในเครื่องของคุณเอง รวมถึงไดรฟ์อื่น และจำไว้ว่าแต่ละโปรแกรมเปิดจากที่ไหน ถ้าโปรแกรมอยู่ในที่ที่ Boom หาไม่เจอ (เช่น แบบพกพา) บอกที่อยู่เต็มให้ GPT ครั้งเดียวพอ

เพิ่มวิธีทำงานของคุณเองได้: วางโฟลเดอร์ที่มีไฟล์ `SKILL.md` ไว้ใน `%LOCALAPPDATA%\BoomLocalMCP\knowhow` Boom อ่านเป็นข้อความอย่างเดียว ไม่รันสคริปต์ที่มากับมัน และวิธีทำงานไม่มีสิทธิ์ข้ามการอนุมัติ

## 8. Boom Control

เปิดได้จากไอคอน **B** ที่มุมขวาล่าง

- **ภาพรวม / งาน / การอนุมัติ / กิจกรรม:** ดูทุกคำสั่งที่ GPT ส่งมา งานที่กำลังทำ และประวัติการอนุมัติ
- **ควบคุมหน้าจอ:** พักหรือคืนการควบคุมได้ทุกเมื่อ
- **Workspace:** โฟลเดอร์ที่อนุญาตให้ Boom แก้ไฟล์
- **อัปเดต:** อัปเดตข้ามไปรุ่นล่าสุดได้ทันที ไม่ต้องไล่ทีละรุ่น และ Boom เก็บจุดย้อนกลับ 5 จุดล่าสุด (จุดละไม่กี่ MB) ย้อนกลับหลายรุ่นได้ในครั้งเดียว และกดลบจุดที่ไม่ใช้ได้
- **แจ้งปัญหาให้ผู้พัฒนา:** สร้างไฟล์วินิจฉัย แล้วเขียนอีเมลถึง boomhothkub@gmail.com (Boom ไม่ส่งอะไรออกไปเอง)

## 9. AI ตัวอื่น

## 11. ถอนการติดตั้ง

Windows Settings → Apps → Installed apps → **Boom Local MCP** → Uninstall เลือกได้ว่าจะลบข้อมูลของ Boom ด้วยหรือไม่ (การเชื่อมต่อ API key ประวัติ และการตั้งค่า)

| `BoomSetup-<version>-r<N>.exe` | ตัวติดตั้งและตัวอัปเดต: ติดตั้งใหม่ หรืออัปเดตของเดิมในที่เดิม |
| `boom-<version>-r<N>.zip` | แพ็กเกจที่ Boom Control ดาวน์โหลดตอนอัปเดตในแอป |
| `release.json`, `release.json.sig` | รุ่น บิลด์ และ SHA-256 ของแพ็กเกจ ลงลายเซ็นด้วยกุญแจ release ของ Boom (ECDSA P-256) |

Boom ตรวจไฟล์ทุกไฟล์ก่อนใช้:
- ไม่ติดตั้งอะไรเลยถ้า `release.json` ไม่ได้ลงลายเซ็นด้วยกุญแจของ Boom หรือแพ็กเกจขนาดและ SHA-256 ไม่ตรง
- ตัวติดตั้งตรวจทุกไฟล์เทียบกับรายการในแพ็กเกจ ถ้ารุ่นใหม่เปิดไม่ขึ้น Boom ย้อนกลับรุ่นเดิมให้
